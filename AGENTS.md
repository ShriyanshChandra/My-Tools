# Agent Rules

## DOM Usage Rule
- Only use DOM tools and DOM inspection when explicitly requested by the user, and strictly only for that specific prompt/task.

## Emoji Usage Rule
- Never use emojis in responses, documentation, UI text, or code unless explicitly requested by the user.

## CSS Rule
- Never use !important every in code. This will make the code look unprofessional and messy. Use only when it is really necessary.

## Responsiveness Rule
- Whenever implementing something new (pages, components, or UI layouts), always ensure complete mobile and tablet responsiveness across standard viewport breakpoints.
